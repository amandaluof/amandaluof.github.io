# Feng (Amanda) Luo

Personal academic homepage: https://amandaluof.github.io/

## Updating the website

Edit `index.html` for biography and publications, and `styles.css` for appearance.
The profile photo is `feng-luo.jpg`. Commit and push changes to `main`; GitHub Pages publishes from the repository root automatically.

No server, package installation, or build step is required. For a local preview, run `python3 -m http.server 8000` and open http://localhost:8000.
